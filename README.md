# Mohsan-Javed Python Basic Projects

A collection of beginner-friendly Python CLI projects to practice core programming concepts including Object-Oriented Programming (OOP), File I/O, and Data Management.

## Projects (Sorted by Complexity)

### 1. Student Management System (`student_management.py`)
The most advanced project in this collection, utilizing a full Object-Oriented structure with a dedicated management class.
- **Features**:
    - **Unique Student IDs**: Prevents duplicate entries.
    - **Grade Management**: Add numeric grades with built-in error handling.
    - **Search Functionality**: Search by Name or ID with partial matching.
    - **Delete Student**: Safely remove students with a confirmation prompt.
    - **Persistent Storage**: Data is saved to and loaded from `students.json`.
    - **UI Formatting**: Tables with aligned columns for easy reading.

### 2. Contact Book (`contact_book.py`)
A mid-level project focusing on data persistence and dictionary management.
- **Features**:
    - Stores names and phone numbers.
    - Persistent storage using `contacts.json`.
    - Simple CLI search and list functionality.

### 3. CLI Task Manager (`task_manager.py`)
A straightforward project focusing on basic File I/O and list manipulation.
- **Features**:
    - Simple task list management.
    - Permanent storage using `tasks.txt`.
    - Easy-to-use CLI interface.

## Concepts Practiced
- **Classes & Objects**: Encapsulating data and behavior.
- **Separation of Concerns**: Decoupling logic from the user interface.
- **JSON & File Handling**: Working with structured and raw data files.
- **Input Validation**: Ensuring application stability.
- **Pythonic Syntax**: Using `any()`, list comprehensions, and formatted strings.
